## 💡 两条贯穿全局的设计铁律（先记住）

1. **逐对话的提示缓存是神圣的** —— 系统提示在整个对话生命周期内必须逐字节稳定，否则缓存失效、成本暴涨。唯一例外是上下文压缩。
2. **核心是"窄腰"，能力长在边缘** —— 每个核心工具都会出现在每次 API 调用里，所以新增核心工具是最后手段。优先：扩展已有代码 → CLI+skill → service-gated 工具 → 插件 → MCP → 核心工具。
