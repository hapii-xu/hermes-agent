# 01 - 项目概览

> Hermes Agent v0.9.0 — 由 Nous Research 开发的自改进 AI Agent

## 项目简介

Hermes Agent 是一个**自改进的 AI Agent**，它能够：
- 从经验中创建技能（skill）
- 在使用过程中自我改进技能
- 跨多个平台运行（Telegram、Discord、Slack、WhatsApp、Signal、CLI）
- 在多种后端执行终端命令（本地、Docker、SSH、Modal、Daytona、Singularity）

**核心理念**：Agent 不是静态的——它会学习、记忆、并随着使用不断进化。

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.11+ |
| 包管理 | uv (astral.sh/uv) |
| LLM API | OpenAI 兼容 API（支持 OpenRouter、Anthropic、OpenAI 等 200+ 模型） |
| CLI | prompt_toolkit（交互式 TUI）、Rich（终端渲染） |
| 存储 | SQLite（WAL 模式 + FTS5 全文搜索） |
| 消息平台 | python-telegram-bot、discord.py、slack-bolt 等 |
| 配置 | YAML（config.yaml）+ ENV（.env） |

## 核心文件

```
hermes-agent/
├── run_agent.py          # AIAgent 类 — 核心对话循环，工具调度，会话持久化
├── cli.py                # HermesCLI 类 — 交互式 TUI，slash 命令分发
├── model_tools.py        # 工具编排层 — 发现所有工具，handle_function_call()
├── toolsets.py           # 工具集定义和预设分组
├── hermes_state.py       # SQLite 会话数据库（FTS5 搜索）
├── agent/                # Agent 内部组件
│   ├── prompt_builder.py     # 系统提示词组装
│   ├── context_compressor.py # 上下文压缩
│   ├── memory_manager.py     # 记忆管理编排器
│   └── display.py            # 终端 UI（spinner、工具进度）
├── hermes_cli/           # CLI 子命令
│   ├── main.py           # 入口点 — 所有 `hermes` 子命令
│   ├── config.py         # 默认配置、环境变量定义
│   └── commands.py       # Slash 命令中央注册表
├── tools/                # 工具实现（自注册）
│   ├── registry.py       # 中央工具注册表
│   ├── terminal_tool.py  # 终端执行
│   └── environments/     # 终端后端（local/docker/ssh/modal/...）
├── gateway/              # 消息平台网关
│   ├── run.py            # GatewayRunner — 平台生命周期、消息路由
│   └── platforms/        # 平台适配器（telegram/discord/slack/...）
├── skills/               # 捆绑技能（随安装提供）
└── optional-skills/      # 可选技能（可发现，默认不激活）
```

## 两种运行模式

### 1. CLI 模式（交互式终端）
```bash
hermes              # 启动交互式 TUI
hermes -q "Hello"   # 静默单次查询
```
- 使用 `prompt_toolkit` 构建交互式终端
- 支持 slash 命令自动补全、对话历史、流式工具输出
- 入口：`hermes_cli.main:main` → `cli.py:HermesCLI`

### 2. Gateway 模式（消息平台）
```bash
hermes gateway start    # 启动消息网关
```
- 同时监听多个平台（Telegram、Discord、Slack、WhatsApp、Signal）
- 入口：`gateway/run.py:GatewayRunner`
- 每个平台是一个独立的异步适配器（adapter）

## 文件依赖链

```
tools/registry.py          （无依赖 — 被所有工具文件导入）
       ↑
tools/*.py                 （每个文件在导入时调用 registry.register()）
       ↑
model_tools.py             （导入 registry + 触发工具发现）
       ↑
run_agent.py, cli.py,      （消费工具列表，构建 Agent）
batch_runner.py, etc.
```

## 用户配置存储

所有用户配置存储在 `~/.hermes/` 目录下：

| 路径 | 用途 |
|------|------|
| `~/.hermes/config.yaml` | 设置（模型、终端、工具集、压缩等） |
| `~/.hermes/.env` | API 密钥和机密信息 |
| `~/.hermes/auth.json` | OAuth 凭证 |
| `~/.hermes/skills/` | 所有活跃技能 |
| `~/.hermes/memories/` | 持久记忆（MEMORY.md、USER.md） |
| `~/.hermes/state.db` | SQLite 会话数据库 |
| `~/.hermes/sessions/` | JSON 会话日志 |
| `~/.hermes/cron/` | 定时任务数据 |

## 安装与开发

```bash
# 快速安装
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 开发环境
git clone --recurse-submodules https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
uv venv venv --python 3.11
uv pip install -e ".[all,dev]"
python -m pytest tests/ -q   # 运行 ~3000 个测试
```
