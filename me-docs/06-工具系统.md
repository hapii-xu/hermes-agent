# 06 - 工具系统

> AI 如何通过工具（Tools）与外部世界交互

## 概览

工具是 Hermes 与外部世界交互的**代码接口** — 让 Agent 能够执行搜索、操作文件、运行命令、浏览网页等。

```
用户: "搜索最新的 Python 新闻"
Agent: 调用 web_search(query="Python 新闻 2024")
     → 调用 Firecrawl API
     → 返回搜索结果 JSON
     → Agent 整理后回复用户
```

## 工具注册机制

### 自注册模式

每个工具文件在**导入时自动注册**到中央注册表：

**文件**: `tools/registry.py`

```python
# tools/web_tools.py（示例）
from tools.registry import registry

def web_search(query: str, **kwargs) -> str:
    """执行网页搜索并返回结果。"""
    results = do_search(query)
    return json.dumps(results)

WEB_SEARCH_SCHEMA = {
    "name": "web_search",
    "description": "Search the web for information.",
    "parameters": {
        "type": "object",
        "properties": {
            "query": {"type": "string", "description": "Search query"},
        },
        "required": ["query"],
    },
}

def _check_requirements() -> bool:
    return bool(os.getenv("FIRECRAWL_API_KEY"))

registry.register(
    name="web_search",
    toolset="web",
    schema=WEB_SEARCH_SCHEMA,
    handler=lambda args, **kw: web_search(**args, **kw),
    check_fn=_check_requirements,
    requires_env=["FIRECRAWL_API_KEY"],
)
```

### 工具发现链

```
model_tools.py 导入时
    │
    ├── discover_builtin_tools()
    │     扫描 tools/*.py 文件
    │     用 AST 分析查找 registry.register() 调用
    │     导入每个符合条件的模块
    │          │
    │          └── 每个模块导入时自动调用 registry.register()
    │
    ├── discover_mcp_tools()
    │     从配置中读取 MCP 服务器
    │     连接到 MCP 服务器获取工具列表
    │
    └── discover_plugins()
          扫描 plugins/ 目录
          加载插件注册的工具
```

### 发现代码（AST 分析）

**文件**: `tools/registry.py:discover_builtin_tools()`

```python
def discover_builtin_tools(tools_dir=None):
    """导入内置的自注册工具模块。"""
    module_names = [
        f"tools.{path.stem}"
        for path in sorted(tools_path.glob("*.py"))
        if path.name not in {"__init__.py", "registry.py", "mcp_tool.py"}
        and _module_registers_tools(path)   # AST 分析
    ]
    for mod_name in module_names:
        importlib.import_module(mod_name)   # 触发 registry.register()
```

`_module_registers_tools()` 使用 Python AST 模块分析文件顶层是否有 `registry.register(...)` 调用。

## ToolRegistry 类

**文件**: `tools/registry.py`

### 核心数据结构

```python
class ToolEntry:
    """单个已注册工具的元数据。"""
    name: str                # 工具名称
    toolset: str             # 所属工具集
    schema: dict             # OpenAI 格式的函数调用 schema
    handler: Callable        # 执行函数
    check_fn: Callable       # 可用性检查函数
    requires_env: list       # 需要的环境变量
    is_async: bool           # 是否为异步工具
    description: str         # 描述
    emoji: str               # 终端显示的表情符号
    max_result_size_chars: int  # 结果大小限制

class ToolRegistry:
    _tools: Dict[str, ToolEntry]           # 名称 → 工具条目
    _toolset_checks: Dict[str, Callable]   # 工具集 → 检查函数
    _toolset_aliases: Dict[str, str]       # 工具集别名
    _lock: threading.RLock                 # 线程安全锁
```

### 核心方法

| 方法 | 作用 |
|------|------|
| `register()` | 注册工具（模块导入时调用） |
| `deregister()` | 注销工具（MCP 动态刷新时使用） |
| `get_definitions()` | 获取 OpenAI 格式的工具 schema 列表 |
| `dispatch()` | 执行工具处理器 |
| `is_toolset_available()` | 检查工具集是否可用 |
| `get_available_toolsets()` | 获取所有工具集的元数据 |

## 工具分发（Dispatch）

**文件**: `tools/registry.py:dispatch()` + `model_tools.py:handle_function_call()`

### 分发流程

```python
def dispatch(name, args, **kwargs) -> str:
    """通过名称执行工具处理器。"""
    entry = self.get_entry(name)
    if not entry:
        return json.dumps({"error": f"Unknown tool: {name}"})
    try:
        if entry.is_async:
            return _run_async(entry.handler(args, **kwargs))
        return entry.handler(args, **kwargs)
    except Exception as e:
        logger.exception("Tool %s dispatch error: %s", name, e)
        return json.dumps({"error": f"Tool execution failed: {type(e).__name__}: {e}"})
```

### 异步工具桥接

**文件**: `model_tools.py`

```python
def _run_async(coro):
    """在同步上下文中运行异步协程。"""
    # 1. 如果当前线程已有运行中的事件循环 → 新线程执行
    # 2. 如果是工作线程 → 使用线程专用的持久化 loop
    # 3. 如果是主线程（CLI）→ 使用全局持久化 loop
```

这解决了 `asyncio.run()` 创建和销毁 loop 导致的 "Event loop is closed" 错误。

## 终端后端（Environments）

**文件**: `tools/environments/`

终端命令在不同的后端执行：

```
tools/environments/
├── base.py          # BaseEnvironment 抽象基类
├── local.py         # 本地执行（默认）
├── docker.py        # Docker 容器
├── ssh.py           # SSH 远程
├── modal.py         # Modal 云函数
├── daytona.py       # Daytona 沙箱
└── singularity.py   # Singularity 容器
```

### 后端抽象

```python
class BaseEnvironment(ABC):
    @abstractmethod
    def run_command(self, command, timeout=None):
        """执行命令，返回 (output, exit_code)。"""

    @abstractmethod
    def write_file(self, path, content):
        """写入文件到环境中。"""

    @abstractmethod
    def read_file(self, path):
        """从环境读取文件。"""
```

### Docker 后端的安全限制

```python
# Docker 容器以最小权限运行
```

## 添加工具的流程

### 需要修改 2 个文件

1. **创建 `tools/your_tool.py`**：
```python
import json
from tools.registry import registry

def your_tool(param: str, **kwargs) -> str:
    return json.dumps({"success": True, "data": "..."})

registry.register(
    name="your_tool",
    toolset="your_toolset",
    schema={"name": "your_tool", "description": "...", "parameters": {...}},
    handler=lambda args, **kw: your_tool(**args, **kw),
    check_fn=lambda: True,
)
```

2. **添加到 `toolsets.py`**：
```python
# 添加到 _HERMES_CORE_TOOLS 列表
# 或创建新工具集
```

无需手动维护导入列表 — 自注册机制会自动发现。
