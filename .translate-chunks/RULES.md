# 翻译规则（英文 skill → 简体中文）

你正在把 Claude skill 文档从英文翻译成简体中文，目的是帮助用户学习。
请逐个文件读取 → 翻译 → 用 **Write 工具覆盖写回原路径**（原地覆盖，路径不变）。

## 必须翻译
- 所有正文（标题、段落、列表项、表格单元格里的英文文字）翻译成自然流畅的简体中文。
- YAML frontmatter 里的 **人类可读字段**也翻译，例如 `description:` 的值。
- 代码块（``` 包裹）里**仅翻译注释**（`#`、`//`、`/* */`、`<!-- -->`、`--` 等注释的**文字内容**），翻译后保持注释语法标记和周围代码完全不变。

## 必须保留、不要翻译
- YAML frontmatter 的 `name:` 字段值（它是标识符，例如 `apple-notes`，保持原样）。
- 代码块里的代码、命令、变量名、函数名、API 字段名、配置键名（除了注释以外全部不动）。
- 行内代码 `` `like_this` `` 里的内容不动。
- URL、文件路径、库名/工具名（p5.js、Manim、ComfyUI、TouchDesigner、MCP、SDK、API、GPU 等）。
- CLI 参数、环境变量、版本号、尺寸单位。
- Markdown 结构（标题层级 `#`、表格 `|`、列表 `-`、引用 `>`、链接）保持不变。**链接的显示文字可翻译，链接 URL 不动。**

## 术语处理
- 通用技术缩写（API、SDK、MCP、GPU、CLI、JSON、HTTP、URL、CSS、HTML、GPU 等）保持英文，不强行翻译。
- 专业术语首次出现时可写「中文（English）」，之后用中文即可，例如「着色器（shader）」。
- 人名、公司名、产品名保持英文原名（如 Claude、Anthropic、Linear、Figma、Stripe）。

## 格式与安全
- 保持原有 Markdown 结构、空行、缩进、emoji、HTML 标签（`<note>` 等）。HTML 标签内的文字翻译，标签本身不动。
- frontmatter 用 `---` 包裹的结构不要破坏。只改字段**值**，不改键名。
- **务必覆盖写回每一个文件**，不要跳过、不要只翻译一部分。每个文件都要完整翻译完整写回。
- 表格里的内容翻译，但 `|` 分隔和 `---` 对齐行保留。
- 如果某文件几乎是空的（只有几行），也照常翻译那几行后写回。

## 完成后
统计：翻译了几个文件、是否有无法处理的情况。简短汇报即可。
