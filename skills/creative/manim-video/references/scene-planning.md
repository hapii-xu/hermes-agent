# 场景规划参考

## 叙事弧线结构

### 发现弧（最常见）
1. 钩子 —— 抛出一个问题或令人惊讶的结果
2. 直觉 —— 建立视觉理解
3. 形式化 —— 引入公式/算法
4. 揭示 —— "顿悟时刻"
5. 拓展 —— 推论或推广

### 问题—解决弧
1. 问题 —— 哪里坏了
2. 失败的尝试 —— 显而易见的做法行不通
3. 关键洞见 —— 行得通的那个想法
4. 解决方案 —— 实施它
5. 结果 —— 展示改进

### 对比弧
1. 设定 —— 引入两种方法
2. 方法 A —— 它如何工作
3. 方法 B —— 它如何工作
4. 对比 —— 差异
5. 结论 —— 哪个更好

### 逐步搭建弧（架构/系统类）
1. 组件 A —— 第一块
2. 组件 B —— 第二块
3. 连接 —— 它们如何互动
4. 扩展 —— 加入更多块
5. 全景 —— 缩小看全貌

## 场景过渡

### 干净中断（默认）
```python
self.play(FadeOut(Group(*self.mobjects)), run_time=0.5)
self.wait(0.3)
```

### 承接延续
保留一个元素，淡出其余。下一个场景从这个仍可见的元素开始。

### 变换桥梁
上一个场景以一个形状结束，下一个场景从这个形状变换开始。

## 场景检查清单

- [ ] 已设置背景色
- [ ] 每个动画都有 subcaption
- [ ] 每次揭示之后都有 `self.wait()`
- [ ] 边缘定位的文字 buff >= 0.5
- [ ] 没有文字重叠
- [ ] 使用了颜色常量（非硬编码）
- [ ] 应用了透明度分层
- [ ] 场景结尾有干净退出
- [ ] 同时可见的元素不超过 5-6 个

## 时长估算

| 内容 | 时长 |
|---------|----------|
| 标题卡 | 3-5s |
| 概念引入 | 10-20s |
| 公式揭示 | 15-25s |
| 算法步骤 | 5-10s |
| 数据对比 | 10-15s |
| "顿悟时刻" | 15-30s |
| 结论 | 5-10s |
