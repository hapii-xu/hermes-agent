# periodic-table

分类元素组成的网格，单元格格式统一。

## 结构

- 矩形网格
- 每个单元格代表一个元素
- 类别用颜色编码
- 单元格格式一致
- 可选的分组间隔

## 最适用于

- 分类集合
- 工具/资源目录
- 技能矩阵
- 元素合集
- 参考指南

## 视觉元素

- 统一的单元格尺寸
- 类别颜色
- 符号/缩写突出
- 每个单元格配小图标
- 类别图例

## 文字排布

- 标题置于顶部
- 单元格内：符号、名称、简短信息
- 图例中标注类别名称
- 可选的行/列表头
- 特殊情况配脚注

## 推荐搭配

- `pop-art`：鲜亮的元素网格
- `pixel-art`：复古合集展示
- `corporate-memphis`：商业工具目录
