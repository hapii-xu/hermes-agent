# 结构化内容模板

用于生成结构化信息图内容的模板，为视觉设计师提供依据。

## 目的

本文档在内容分析与视觉设计之间起到桥梁作用：
- 将源材料转化为设计师可直接使用的格式
- 把学习目标组织成视觉分区
- 逐字保留所有源数据
- 将内容与设计指令分离

## 教学设计流程

### 阶段 1：高层大纲

1. **标题**：用一个引人注目的头条概括核心要义
2. **概述**：简短描述（1-2 句话）
3. **学习目标**：列出受众将理解的内容

### 阶段 2：分区展开

针对每个学习目标：

1. **核心概念**：用一句话概括本部分
2. **内容**：从源材料逐字提取的要点
3. **视觉元素**：应该在视觉上展示什么
4. **文字标签**：标题、副标题、标签的精确文字

### 阶段 3：数据完整性检查

核验所有源数据是否：
- 精确复制（无改写）
- 署名正确（针对引述）
- 格式一致

## 关键规则

| 规则 | 要求 | 示例 |
|------|-------------|---------|
| **输出格式** | 仅使用 Markdown | 使用规范的标题、列表、代码块 |
| **语气** | 专家讲师 | 专业、清晰、有鼓励性 |
| **不新增信息** | 仅限源内容 | 不要加入源材料中没有的示例 |
| **逐字数据** | 精确复制 | "增长 73%" 而非 "显著增长" |

## 结构化内容格式

```markdown
# [信息图标题]

## 概述
[简短描述本信息图传达的内容 - 1-2 句话]

## 学习目标
受众将理解：
1. [主要目标]
2. [次要目标]
3. [如有的第三目标]

---

## 第 1 部分：[部分标题]

**核心概念**：[用一句话概括本部分]

**内容**：
- [要点 1 - 源文逐字]
- [要点 2 - 源文逐字]
- [要点 3 - 源文逐字]

**视觉元素**：[描述要展示什么]
- 类型：[图标/图表/插画/示意图/照片]
- 主体：[描绘什么]
- 处理：[应当如何呈现]

**文字标签**：
- 标题："[标题精确文字]"
- 副标题："[副标题精确文字]"
- 标签："[标签 1]"、"[标签 2]"、"[标签 3]"

---

## 第 2 部分：[部分标题]

**核心概念**：[一句话概括]

**内容**：
- [要点 1]
- [要点 2]

**视觉元素**：[描述]

**文字标签**：
- 标题："[文字]"
- 标签："[标签 1]"、"[标签 2]"

---

[对每个部分依此类推……]

---

## 数据点（逐字）

所有统计数字、数字和引述，与源文完全一致：

### 统计数字
- "[精确统计 1]"
- "[精确统计 2]"
- "[精确统计 3]"

### 引述
- "[精确引述]" — [署名]

### 关键术语
- **[术语 1]**：[来自源文的定义]
- **[术语 2]**：[来自源文的定义]

---

## 设计指令

从用户的引导提示词中提取：

### 风格偏好
- [任何颜色偏好]
- [任何氛围/美学偏好]
- [任何艺术风格偏好]

### 布局偏好
- [任何结构偏好]
- [任何组织偏好]

### 其他要求
- [用户提出的任何其他视觉要求]
- [如指定的目标平台]
- [如有品牌规范]
```

## 按内容划分的分区类型

### 流程/步骤类

```markdown
## 第 N 部分：第 N 步 - [步骤标题]

**核心概念**：[本步骤达成什么]

**内容**：
- 动作：[做什么]
- 细节：[怎么做]
- 注意：[重要考量]

**视觉元素**：
- 类型：编号步骤图标
- 主体：[代表该动作的视觉]
- 箭头：指向下一步

**文字标签**：
- 标题："第 N 步：[标题]"
- 动作："[祈使动词 + 宾语]"
```

### 对比类

```markdown
## 第 N 部分：[条目 A] 对 [条目 B]

**核心概念**：[两者的区分点]

**内容**：
| 方面 | [条目 A] | [条目 B] |
|--------|----------|----------|
| [因素 1] | [取值] | [取值] |
| [因素 2] | [取值] | [取值] |

**视觉元素**：
- 类型：分屏对比
- 左侧：[条目 A 的呈现]
- 右侧：[条目 B 的呈现]

**文字标签**：
- 标题："[条目 A] 对 [条目 B]"
- 左侧标签："[条目 A 名称]"
- 右侧标签："[条目 B 名称]"
```

### 层级类

```markdown
## 第 N 部分：[层级名称]

**核心概念**：[本层级代表什么]

**内容**：
- 位置：[顶层/中层/底层]
- 优先级：[重要程度]
- 包含：[本层级的元素]

**视觉元素**：
- 类型：层/级
- 大小：[相对于其他层级]
- 位置：[在层级中的位置]

**文字标签**：
- 层级标题："[名称]"
- 描述："[简短描述]"
```

### 数据/统计类

```markdown
## 第 N 部分：[指标名称]

**核心概念**：[这组数据说明什么]

**内容**：
- 数值：[精确数字/百分比]
- 背景：[含义]
- 对比：[如有基准]

**视觉元素**：
- 类型：[图表/数字突出/仪表]
- 强调：[如何吸引注意]

**文字标签**：
- 主数字："[精确数值]"
- 标签："[指标名称]"
- 背景："[简短背景]"
```

## 质量检查清单

在定稿结构化内容之前：

- [ ] 标题是否概括了主旨
- [ ] 学习目标是否清晰可衡量
- [ ] 每个分区是否对应一个目标
- [ ] 所有内容是否均逐字取自源文
- [ ] 视觉元素是否描述清晰
- [ ] 文字标签是否精确指定
- [ ] 数据点是否已收集并核验
- [ ] 设计指令是否已分离
- [ ] 是否未添加任何新信息
